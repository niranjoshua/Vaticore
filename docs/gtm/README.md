# Go-to-market kit

Business-facing documents for landing the first design-partner pilots. Product and build docs live in `VATICORE_BRIEF.md` and `CLAUDE.md`; this folder is about getting Vaticore in front of operators.

- **`overview.md`**: the full plain-language summary of what Vaticore is, the problem, solution, strategy, customers, and exactly what a customer gets.
- **`startup-plan.md`**: the prioritised plan and realistic timeline from working repo to paying operators, across all six workstreams.
- **`linkedin-kit.md`**: founder headline, About section, launch post, and a four-week content calendar.
- **`pilot-proposal.md`**: the one-page free shadow-mode pilot offer to send an operator.
- **`outreach-emails.md`**: cold, warm, and follow-up templates, plus a discovery-call agenda.
- **`data-request-checklist.md`**: exactly what data we need from an operator to run a pilot.
- **`data-and-trust.md`**: the plain-language "you own your data, advisory only" one-pager.
- **`results-onepager.md`**: current backtest evidence translated into diesel, cost and CO2.

The illustrative savings figures in `results-onepager.md` are generated by `examples/operator_savings.py`, whose assumptions are all explicit and editable. Replace them with a real site's numbers, then replace the estimate with a pilot measurement.
